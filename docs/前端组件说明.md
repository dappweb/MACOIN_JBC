## 2. 核心组件说明

### 2.1 Web3Context (`src/Web3Context.tsx`)

**功能：** 全局Web3状态管理

**提供的状态和方法：**

```typescript
interface Web3ContextType {
  // 连接状态
  isConnected: boolean;
  account: string | null;
  provider: ethers.BrowserProvider | null;
  signer: ethers.Signer | null;
  
  // 合约实例
  protocolContract: ethers.Contract | null;
  jbcContract: ethers.Contract | null;
  
  // 用户信息
  isOwner: boolean;        // 是否是合约Owner
  mcBalance: bigint | null; // MC余额
  jbcBalance: bigint | null; // JBC余额
  
  // 方法
  connect: () => Promise<void>;
  disconnect: () => void;
  refreshMcBalance: () => Promise<void>;
  refreshJbcBalance: () => Promise<void>;
}
```

**使用方式：**

```typescript
import { useWeb3 } from '@/src/Web3Context';

function MyComponent() {
  const { 
    account, 
    isConnected, 
    protocolContract,
    mcBalance,
    isOwner 
  } = useWeb3();
  
  // 使用合约
  const userInfo = await protocolContract.userInfo(account);
}
```

### 2.2 AdminLiquidityPanel (`components/AdminLiquidityPanel.tsx`)

**功能：** 管理员添加/移除流动性

**关键逻辑：**

1. **添加JBC流动性流程：**
   ```
   检查Owner权限 → 检查JBC余额 → 授权JBC → 等待授权生效 → 
   重新检查MC余额(gas费) → 静态调用验证 → 发送交易 → 等待确认
   ```

2. **错误处理：**
   - `OwnableUnauthorizedAccount` - 不是Owner
   - `ERC20InsufficientAllowance` - JBC授权不足
   - `TransferFromFailedLowLevel` - JBC转账失败

**调试技巧：**

```javascript
// 在浏览器控制台查看调试日志
// 组件会输出详细的执行流程日志
```

## 3. 合约错误解码

### 3.1 错误解码器 (`utils/contractErrorDecoder.ts`)

**支持的错误：**

```typescript
const PROTOCOL_ERRORS = {
  '0x118cdaa7': 'OwnableUnauthorizedAccount',
  '0x82a6e09c': 'TransferFromFailedLowLevel',
  '0xfb8f41b2': 'ERC20InsufficientAllowance',
  '0xe450d38c': 'ERC20InsufficientBalance',
  // ...更多错误
};
```

**使用方式：**

```typescript
import { decodeContractError } from '@/utils/contractErrorDecoder';

try {
  await contract.someFunction();
} catch (error) {
  const decoded = decodeContractError(error);
  console.log('错误类型:', decoded.name);
  console.log('错误参数:', decoded.args);
}
```

## 5. 常见调试场景

### 5.1 组件不显示数据

**检查步骤：**

1. 检查钱包是否连接
```javascript
console.log('isConnected:', useWeb3().isConnected);
```

2. 检查合约实例是否存在
```javascript
console.log('protocol:', useWeb3().protocolContract);
```

3. 检查网络是否正确
```javascript
const network = await provider.getNetwork();
console.log('chainId:', network.chainId);
```

### 5.2 交易失败

**检查步骤：**

1. 打开浏览器控制台查看错误
2. 检查交易参数
3. 使用静态调用测试
```javascript
try {
  await contract.function.staticCall(args);
} catch (e) {
  console.log('静态调用失败:', e);
}
```

### 5.3 数据不一致

**解决方案：**

1. 清除浏览器缓存
2. 刷新页面
3. 直接查询合约验证数据
```javascript
const info = await protocolContract.userInfo(account);
console.log('合约数据:', info);
```
