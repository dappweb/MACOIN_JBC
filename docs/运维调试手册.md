### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| 门票购买 | 用户购买门票激活账户，设置推荐关系 |
| 流动性质押 | 用户质押MC获取收益 (7/15/30天周期) |
| 推荐奖励 | 直推奖励、层级奖励、等级奖励 |
| Swap交换 | MC ↔ JBC AMM交换 |
| 赎回 | 质押到期后赎回本金和收益 |

### 1.3 奖励类型说明

| 类型ID | 名称 | 说明 |
|--------|------|------|
| 0 | 直推奖励 | 直接推荐人获得 |
| 2 | 等级奖励 | 根据V等级获得门票25%的奖励 |
| 3 | 差异奖励 | 层级差异奖励，向上传递 |
| 4 | 极差奖励 | 等级极差奖励 |

### 1.4 V等级体系

| 等级 | 团队人数要求 | 等级奖励比例 |
|------|-------------|-------------|
| V0 | 0 | 0% |
| V1 | ≥10 | 5% |
| V2 | ≥30 | 10% |
| V3 | ≥100 | 15% |
| V4 | ≥300 | 20% |
| V5 | ≥1000 | 25% |

## 5. 用户数据查询

### 5.1 使用 Node.js 快速查询

创建临时脚本或直接运行：

```javascript
// 查询用户基本信息
const { ethers } = require('ethers');

const provider = new ethers.JsonRpcProvider('https://chain.mcerscan.com/');
const protocol = new ethers.Contract(
  '0x77601aC473dB1195A1A9c82229C9bD008a69987A',
  [
    'function userInfo(address) view returns (address referrer, uint256 activeDirects, uint256 teamCount, uint256 totalRevenue, uint256 currentCap, bool isActive, uint256 refundFeeAmount, uint256 teamTotalVolume, uint256 teamTotalCap, uint256 maxTicketAmount, uint256 maxSingleTicketAmount)',
    'function userTicket(address) view returns (uint256 ticketId, uint256 amount, uint256 purchaseTime, bool exited)',
    'function userStakes(address, uint256) view returns (uint256 id, uint256 amount, uint256 startTime, uint256 cycleDays, bool active, uint256 paid)',
    'function getDirectReferrals(address) view returns (address[])',
    'function getUserLevel(address) view returns (uint256 level, uint256 percent, uint256 teamCount)',
  ],
  provider
);

async function queryUser(address) {
  const info = await protocol.userInfo(address);
  const ticket = await protocol.userTicket(address);
  console.log('推荐人:', info.referrer);
  console.log('是否激活:', info.isActive);
  console.log('团队人数:', info.teamCount.toString());
  console.log('总收益:', ethers.formatEther(info.totalRevenue), 'MC');
  console.log('门票金额:', ethers.formatEther(ticket.amount), 'MC');
}

queryUser('0x用户地址');
```

### 5.3 查询推荐链

```javascript
async function getReferralChain(address, maxDepth = 15) {
  let current = address;
  let depth = 0;
  const chain = [];
  
  while (current !== ethers.ZeroAddress && depth < maxDepth) {
    const info = await protocol.userInfo(current);
    chain.push({
      depth,
      address: current,
      teamCount: info.teamCount.toString(),
      isActive: info.isActive
    });
    current = info.referrer;
    depth++;
  }
  
  return chain;
}
```

## 6. 常见问题排查

### 6.1 用户无法购买门票

**症状：** 用户点击购买门票后交易失败

**排查步骤：**

1. 检查用户MC余额是否足够
```javascript
const balance = await provider.getBalance(userAddress);
console.log('MC余额:', ethers.formatEther(balance));
```

2. 检查是否已有门票
```javascript
const ticket = await protocol.userTicket(userAddress);
console.log('现有门票:', ethers.formatEther(ticket.amount));
```

3. 检查推荐人是否有效
```javascript
const userInfo = await protocol.userInfo(userAddress);
console.log('推荐人:', userInfo.referrer);
```

**常见原因：**
- MC余额不足
- 已有未退出的门票
- 推荐人地址无效或未激活

### 6.2 用户无法领取收益

**症状：** 点击领取收益后交易失败或显示0收益

**排查步骤：**

1. 检查是否有活跃质押
```javascript
let hasActiveStake = false;
let i = 0;
while (true) {
  try {
    const stake = await protocol.userStakes(userAddress, i);
    if (stake.active) {
      hasActiveStake = true;
      console.log('活跃质押:', stake);
    }
    i++;
  } catch {
    break;
  }
}
```

2. 检查收益上限
```javascript
const info = await protocol.userInfo(userAddress);
const remaining = info.currentCap - info.totalRevenue;
console.log('剩余额度:', ethers.formatEther(remaining));
```

**常见原因：**
- 没有活跃的质押
- 收益上限已达到
- 门票已退出

### 6.3 管理员无法添加流动性

**症状：** 添加JBC或MC流动性失败

**排查步骤：**

1. 检查是否是合约Owner
```javascript
const owner = await protocol.owner();
const isOwner = owner.toLowerCase() === adminAddress.toLowerCase();
console.log('是否Owner:', isOwner);
```

2. 检查JBC授权
```javascript
const jbcContract = new ethers.Contract(JBC_ADDRESS, ['function allowance(address,address) view returns (uint256)'], provider);
const allowance = await jbcContract.allowance(adminAddress, PROTOCOL_ADDRESS);
console.log('JBC授权额度:', ethers.formatEther(allowance));
```

3. 检查余额
```javascript
const mcBalance = await provider.getBalance(adminAddress);
const jbcBalance = await jbcContract.balanceOf(adminAddress);
console.log('MC余额:', ethers.formatEther(mcBalance));
console.log('JBC余额:', ethers.formatEther(jbcBalance));
```

**常见原因：**
- 不是合约Owner
- JBC授权不足
- MC余额不足（需要预留gas费）
- 授权后链上状态未同步

### 6.4 奖励金额不符预期

**症状：** 用户反馈收到的奖励与预期不符

**排查步骤：**

1. 查询用户的所有奖励事件
```javascript
const events = await protocol.queryFilter(protocol.filters.ReferralRewardPaid(userAddress));
for (const e of events) {
  console.log('区块:', e.blockNumber);
  console.log('MC:', ethers.formatEther(e.args.mcAmount));
  console.log('类型:', e.args.rewardType);
  console.log('来源:', e.args.from);
}
```

2. 检查用户在推荐链中的位置
3. 检查用户的V等级
4. 检查收益上限是否已达

**常见原因：**
- 用户等级较低，奖励比例较少
- 收益上限已达到
- 推荐链位置较低，差异奖励分配较少

### 6.5 交易一直 Pending

**症状：** 交易提交后长时间显示"正在处理"

**排查步骤：**

1. 获取交易哈希，在区块浏览器查询
2. 检查gas价格是否足够
3. 检查nonce是否正确

**解决方案：**
- 等待交易确认或失败
- 如果长时间pending，可以用相同nonce发送新交易替换
- 刷新页面重试

## 8. 已知问题与异常

### 8.1 团队人数统计异常

**问题描述：**
- 地址 `0x4544c0CF9d62D3bB441c04A5F31C1ba0E432d37e` 团队人数 100,188
- 其推荐人 `0x0435aFf9777DafBd0552B54951501D3169A02062` 团队人数仅 10,235
- 理论上被推荐人的团队应该全部计入推荐人的团队

**可能原因：**
- 数据迁移时未正确处理推荐链关系
- 手动设置的特殊账户
- 合约升级导致的数据不一致

**影响：**
- 部分用户的等级计算可能不准确
- 奖励分配可能受影响

### 8.2 差异奖励分配

**机制说明：**
- 差异奖励（类型3）向上传递最多15层
- 每层根据门票金额和等级差异计算奖励
- 同等级不产生差异奖励

### 8.3 前端显示与合约状态差异

**问题描述：**
- 前端"历史奖励统计"可能与合约事件查询结果不一致
- 原因是前端使用缓存和增量更新

**解决方案：**
- 以合约事件查询为准
- 清除浏览器缓存刷新页面

## 9. 监控与告警

### 9.1 关键指标监控

| 指标 | 说明 | 告警阈值 |
|------|------|----------|
| MC储备 | Swap池MC数量 | < 10,000 MC |
| JBC储备 | Swap池JBC数量 | < 100,000 JBC |
| 合约MC余额 | 合约中的MC | < 奖励池的10% |
| 每日交易量 | 门票购买量 | 异常波动 |

### 9.2 监控脚本示例

```javascript
const { ethers } = require('ethers');

async function monitor() {
  const provider = new ethers.JsonRpcProvider('https://chain.mcerscan.com/');
  const protocol = new ethers.Contract(PROTOCOL_ADDRESS, ABI, provider);
  
  const mcReserve = await protocol.swapReserveMC();
  const jbcReserve = await protocol.swapReserveJBC();
  const contractBalance = await provider.getBalance(PROTOCOL_ADDRESS);
  
  console.log('MC储备:', ethers.formatEther(mcReserve));
  console.log('JBC储备:', ethers.formatEther(jbcReserve));
  console.log('合约余额:', ethers.formatEther(contractBalance));
  
  // 告警逻辑
  if (mcReserve < ethers.parseEther('10000')) {
    console.error('⚠️ MC储备不足!');
  }
}

// 每5分钟执行一次
setInterval(monitor, 5 * 60 * 1000);
```
