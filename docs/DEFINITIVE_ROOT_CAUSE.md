### 问题1: 检查脚本的等级规则定义错误（129个"等级不匹配"是误报）

**检查脚本的错误规则** (`scripts/check-data-consistency.cjs`):
```javascript
const levelRules = {
    0: { min: 0, max: 0 },      // ❌ 错误：应该是 0-9
    1: { min: 1, max: 2 },      // ❌ 错误：应该是 10-29
    2: { min: 3, max: 9 },      // ❌ 错误：应该是 30-99
    3: { min: 10, max: 29 },    // ❌ 错误：应该是 100-299
    4: { min: 30, max: 99 },    // ❌ 错误：应该是 300-999
    5: { min: 100, max: 299 },  // ❌ 错误：应该是 1000-2999
    6: { min: 300, max: 999 },  // ❌ 错误：应该是 3000-9999
    7: { min: 1000, max: 2999 },// ❌ 错误：应该是 10000-29999
```

**实际合约的正确规则** (`JinbaoProtocolNative.sol`):
```solidity

    if (value >= 10) return (1, 5);       // V1: 10-29

```

**实际案例验证**:
- 用户: `0x4544c0cf9d62d3bb441c04a5f31c1ba0e432d37e`
- 团队人数: 804
- 当前等级: V4
- 检查脚本认为: V4应该是30-99，804不在范围内 → 报错 ❌
- 实际合约标准: V4是300-999，804在范围内 → 正确 ✅

**结论**: 129个"等级不匹配"问题都是**误报**！用户的等级都是正确的，只是检查脚本的规则定义错了。
