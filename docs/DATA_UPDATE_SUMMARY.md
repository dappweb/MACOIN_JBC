1. **动态更新**：
   - 当新用户注册时，合约会自动更新推荐人的 `teamCount`

   - 某些下级用户的 `teamCount` 可能包含了历史数据
   - 这些数据可能不准确，导致上级的 `teamCount` 小于下级的

3. **推荐关系变更**：
   - 如果推荐关系发生过变更，但 `teamCount` 没有正确更新
   - 可能导致数据不一致
