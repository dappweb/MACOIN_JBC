# 改进建议和修复空间

## 📊 价格图表相关

### 1. EMA 计算问题
**问题**：`SwapPanel.tsx` 中 EMA 值直接使用价格值，没有真正计算
```typescript
// 当前代码（第210行）
ema: point.price, // EMA 计算已在 hook 中处理
```
**建议**：
- 在 `useRealTimePrice.ts` 中实现真正的 EMA(7) 计算
- 或者从 `priceHistory` 中正确计算 EMA

### 2. 价格数据初始化
**问题**：初始化时使用随机波动模拟历史数据（第306行）
```typescript
const variation = (Math.random() - 0.5) * 0.04; // ±2%
const price = basePrice * (1 + variation);
```
**建议**：
- 尝试从历史区块查询真实的池子储备数据
- 或者从后端 API 获取历史价格数据

### 3. 控制台日志过多
**问题**：生产环境中有大量 `console.log/warn/error`
**建议**：
- 添加日志级别控制（开发/生产环境）
- 使用环境变量控制日志输出
- 移除或注释掉调试日志

## 🔧 错误处理优化

### 1. 错误提示统一化
**问题**：错误提示分散在多个地方，格式不统一
**建议**：
- 统一使用 `ToastEnhancer` 或 `showFriendlyError`
- 创建错误码映射表
- 提供更具体的错误解决方案

### 2. Gas 估算失败处理
**问题**：Gas 估算失败时的处理逻辑可以更完善
**建议**：
- 添加重试机制
- 提供更详细的错误原因
- 区分不同类型的失败（网络、授权、余额等）

### 3. 网络错误处理
**问题**：网络错误时的重试机制不完善
**建议**：
- 添加指数退避重试
- 提供网络状态检测
- 显示网络连接状态
