# 修复 teamCount 错误用户指南

## 📋 概述

根据最新的验证结果，共有 **92 个用户**存在 `teamCount` 错误，其中：
- **严重错误**（差异 > 100）: 32 个用户
- **中等错误**（差异 10-100）: 7 个用户
- **轻微错误**（差异 < 10）: 53 个用户

## 🔧 修复步骤

### 1. 准备环境变量

确保 `.env` 文件中设置了以下变量：

```bash
PRIVATE_KEY=你的私钥
RPC_URL=https://chain.mcerscan.com/
PROTOCOL_ADDRESS=0x0897Cee05E43B2eCf331cd80f881c211eb86844E
```

**⚠️ 重要**: 
- 确保私钥对应的账户是合约的 `owner`
- 私钥必须保密，不要提交到代码仓库

### 2. 运行修复脚本

```bash
node scripts/fix-team-count-errors-batch.cjs output/team-count-verification-2026-01-16T02-43-51-657Z.json
```

脚本会：
1. 从验证结果文件中读取所有错误用户
2. 使用事件统计方法重新计算每个用户的正确 `teamCount`
3. 按严重程度排序（先修复严重错误）
4. 批量调用 `adminSetTeamCount` 修复每个用户
5. 验证修复结果并生成报告

### 3. 修复过程

- 脚本会按严重程度排序，优先修复严重错误
- 每个修复操作之间会等待 2 秒，避免 RPC 限流
- 修复结果会实时显示在控制台
- 最终结果会保存到 `output/fix-team-count-results-<timestamp>.json`

### 4. 验证修复结果

修复完成后，可以重新运行验证脚本确认：

```bash
node scripts/verify-all-users-team-count.cjs
```

## 📊 预期结果

修复完成后，应该看到：
- ✅ 修复成功: 大部分错误用户（严重和中等错误）
- ⏭️ 跳过: 一些计算值为 0 但合约值 > 0 的用户（需要进一步检查）
- ❌ 修复失败: 极少数可能因为网络或其他原因失败的用户
