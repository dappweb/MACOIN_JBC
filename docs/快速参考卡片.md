## 📊 合约查询 (Node.js)

### 初始化连接
```javascript
const { ethers } = require('ethers');
const provider = new ethers.JsonRpcProvider('https://chain.mcerscan.com/');
const protocol = new ethers.Contract(
  '0x77601aC473dB1195A1A9c82229C9bD008a69987A',
  ABI,
  provider
);
```

### 查询用户信息
```javascript
const info = await protocol.userInfo('0x地址');
// 返回: referrer, activeDirects, teamCount, totalRevenue, currentCap, isActive...
```

### 查询门票
```javascript
const ticket = await protocol.userTicket('0x地址');
// 返回: ticketId, amount, purchaseTime, exited
```

### 查询质押
```javascript
const stake = await protocol.userStakes('0x地址', 0); // 第0个质押
// 返回: id, amount, startTime, cycleDays, active, paid
```

### 查询等级
```javascript
const level = await protocol.getUserLevel('0x地址');
// 返回: level, percent, teamCount
```

### 查询Swap储备
```javascript
const mcReserve = await protocol.swapReserveMC();
const jbcReserve = await protocol.swapReserveJBC();
```
